# 문수로 비스타 더파크 관심고객 등록 웹사이트 (공인중개사용)

공식 홈페이지([https://munsuro-vista-park.com/](https://munsuro-vista-park.com/))의 고급스러운 비주얼 아이덴티티(딥 에메랄드 그린, 샴페인 골드)와 핵심 분양 정보를 반영하여 제작된 **모바일 최적화 반응형 관심고객 등록 랜딩페이지**입니다.

---

## 🌟 주요 특징 및 장점

1. **공식 홈페이지 디자인 톤앤매너 완벽 반영**
   - 딥 포레스트 그린(`Dark Green`) & 샴페인 골드(`Gold`) 컬러 시스템
   - 세련된 카드 레이아웃과 감각적인 폰트 적용 (Pretendard & Montserrat)
2. **모바일 퍼스트 & 반응형 웹**
   - 스마트폰 화면에 완벽하게 맞춘 터치 인터페이스
   - **하단 고정 플로팅 액션바**: [📞 전화상담] [💬 문자문의] [📝 관심고객등록] 원터치 지원
3. **심플하고 직관적인 원페이지 구성**
   - 불필요한 페이지 이동 없이, 고객이 스크롤하면서 핵심 정보(사업개요, 6대 프리미엄, 혜택)를 보고 즉시 등록할 수 있는 구조
4. **공인중개사 전용 고객 관리자 패널 (Admin)**
   - 별도 서버나 데이터베이스 구축 없이도 브라우저에 고객 DB 누적 저장
   - 푸터 하단의 `🔒 공인중개사 고객관리 (Admin)` 클릭 (초기 비밀번호: `1234`)
   - 실시간 접수 명단 조회 및 **한글 깨짐 없는 엑셀(CSV) 원클릭 다운로드** 지원
   - 개별 삭제 및 전체 삭제 관리 기능 탑재

## ⚙️ 공인중개사 정보 수정 방법 (`js/config.js`)

`js/config.js` 파일을 메모장이나 에디터로 열어 아래 항목을 대표님의 실제 정보로 변경하시면 사이트 전체(헤더, 본문, 푸터, 전화/문자 연결)에 자동 반영됩니다:

```javascript
const SITE_CONFIG = {
  agency: {
    name: "이룬다 공인중개사사무소",            // 중개업소 상호명
    representative: "장혜경 소장 (대표 공인중개사)", // 대표 공인중개사 성함
    regNumber: "31140202500096",               // 중개업소 개설등록번호
    mobile: "010-2772-1719",                   // 상담 직통 휴대폰 번호 (전화/문자)
    address: "울산광역시 남구 화합로148번길 12, 1층", // 사무소 주소
  },
  admin: {
    password: "1234",                          // 고객 관리자 접속 비밀번호
  }
};
```

## 🔐 고객 명단 확인 및 엑셀 다운로드 (Admin 모드)

1. 웹사이트 맨 아래 푸터(Footer) 우측 하단의 **[🔒 공인중개사 고객관리 (Admin)]** 버튼을 클릭합니다.
2. 관리자 비밀번호(초기값: `1234`)를 입력하고 로그인합니다.
3. 등록된 고객들의 **성함, 연락처, 희망평형, 목적, 거주지, 문의내용**을 확인하실 수 있습니다.
4. **[📥 엑셀(CSV) 다운로드]** 버튼을 누르면 엑셀에서 바로 열리는 CSV 파일로 안전하게 저장됩니다.

## 🚀 배포 및 호스팅 안내

- 별도의 서버나 빌드 작업이 필요 없는 순수 HTML/CSS/JS로 제작되어 있습니다.
- 개인 도메인 및 호스팅(카페24, 가비아 등)의 `html` 폴더에 파일들을 그대로 업로드하시거나,
- **Netlify**, **Vercel**, **GitHub Pages** 등의 무료 정적 웹호스팅 서비스를 이용하시면 도메인 연결 및 SSL 보안인증서(HTTPS)가 무료로 5분 만에 적용됩니다.
